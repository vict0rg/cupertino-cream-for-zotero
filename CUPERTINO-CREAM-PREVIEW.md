# Cupertino Cream for Zotero — Design preview branch

This is a **non-release development branch**. It keeps the v0.2.2
extension functionality but introduces warm palette overrides
coordinated with the proposed Obsidian theme **Cupertino Cream**.

The current published release remains unchanged. Once the repository
is renamed to `vict0rg/cupertino-cream-for-zotero`, update the manifest,
release URL, update service and documentation before publishing
a numbered release. Keep the add-on ID stable for existing users.

Shared colors:

- Paper: `#FFFDF9`
- Soft Cream PDF: `#F7F1E5`
- Sidepane: `#F3EDE5`
- Toolbar: `#EEE5DC`
- Text: `#332E2B`
- Red accent: `#FF3B30` (titles and selection markers)
- Calm red title text: `#AC3833`

The visual changes are in `Cupertino-Zotero/style.css`.
